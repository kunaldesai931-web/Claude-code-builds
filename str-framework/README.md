# International STR Real-Estate Framework — for an Indian Tax Resident

A rigorous, reusable screening framework for international short-term-rental (STR) property
investment by an Indian tax resident, applied to four target markets: **Bali, Phuket,
Gold Coast, and Dubai**.

Built to the same analytical standard as an equity framework stack — headline rental yield
is treated with the same skepticism as a stock's headline P/E, and the dominant lens is the
**Indian-resident friction layer** (DTAA, FEMA/LRS, surcharge cliff, FX, Schedule FA,
regulatory STR risk) that no source-country property pitch shows.

## Headline conclusions

- **In every base case, the after-tax INR IRR (~6–9%) sits below the investor's own
  12–15% equity hurdle.** The case rests on bull scenarios, the FX tailwind, genuine
  diversification, and lifestyle/visa optionality — each of which must be argued explicitly.
- **All four markets are at a forecast cycle peak (~2026, per the 18-year land cycle).**
  The single highest-value decision is to **phase deployment across the 3–5 year window and
  reserve the largest tranche for the cycle low** — not deploy the full envelope into the peak.
- **Structure quality dominates city choice.** Freehold / PT-PMA-HGB / hotel-licensed
  condo-freehold beat leasehold and quota structures. Most loss in this asset class comes from
  the wrong *structure*, not the wrong *city*.
- **Ranking (risk-adjusted, yield-led):** Dubai > Gold Coast > Phuket > Bali. The two highest-
  *headline*-yield markets (Bali, Phuket) rank last once the ownership-durability and
  Indian-resident tax screens are applied. Recommended core: **Dubai + Gold Coast** (also the
  best diversifier pair), with a Phuket/Bali yield top-up only as a cycle-low option.

## Source discipline

Source tiers are labelled throughout: **T1** regulatory/primary · **T2** institutional/
professional · **T3** marketing/blog (directional only). Data >12 months old is tagged
`STALE`; single-sourced claims are flagged. Several government primary pages (income-tax
portal, BPS, MEA treaty PDFs, GlobalPropertyGuide) blocked automated retrieval and are carried
via T2 sources that reproduce the primary text — **these, and all consequential tax/regulatory
claims, must be verified against the primary source before capital is committed.** This is a
decision framework, not legal or tax advice.
